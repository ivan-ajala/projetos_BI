**Sumário Executivo (para README / LinkedIn)**

Projeto de analytics e data science aplicado ao SECOM dataset (UCI), simulando um ambiente real de qualidade em manufatura de semicondutores. Construí um pipeline em Python para extrair, limpar e preparar mais de 500 variáveis de sensores, corrigindo o mapeamento original dos rótulos (Label -1 = PASS, 1 = FAIL) e trabalhando com um cenário realista de ~93% PASS / 7% FAIL (classe minoritária de falhas). A partir da EDA, identifiquei um subconjunto de sensores com forte relação com FAIL, que foram priorizados tanto no dashboard em Tableau quanto em um modelo preditivo simples (Random Forest com técnicas para desbalanceamento). O resultado é um conjunto de insights e visualizações que ajudam a transformar a gestão de qualidade de uma postura reativa (olhar apenas falhas finais) para uma abordagem mais proativa, baseada em indicadores de risco ao longo do processo.
